# URL Customizer

This repository contains the URL shortener project inside `url-shortner/`.

## Project Location

- App source: `url-shortner/`
- Project README: `url-shortner/README.md`

## Quick Start

```bash
cd url-shortner
npm install
npm run dev
```

Open `http://localhost:3000`.
